# InvoiceEasy V2.5 — Production Hardening

Implemented in this phase:

- First-launch business setup wizard.
- Business settings now include currency and logo selection/removal.
- Report date-range filtering.
- Report export to PDF and CSV through the native share flow.
- App version bumped to 2.5.0.
- Kept the existing offline-first architecture and V2.4 invoice workflows intact.

## Verify

```bash
flutter clean

```
